# Backing audio provenance

Audio files in this directory are **not committed** (see `.gitignore`). Record where
each one came from here instead, so licensing is traceable.

Required if any track is Creative Commons (CC-BY, CC-BY-SA): the attribution must be
shown in the app, not just recorded here. A credits line is a product requirement
(DESIGN.md §3.4), not a nicety.

Format: one row per file.
