# Packages that must be installed with --no-deps.
#
#   pip install -r requirements-optional.txt --no-deps
#
# scripts/setup.sh does this for you. Do NOT install these normally: their own
# declared dependencies cannot be satisfied on a plain Linux box, and we do not
# need them.
#
# tinysoundfont==0.3.7
#   Sampled-instrument rendering. Its declared dependency is pyaudio, which has
#   no Linux wheel in any release and cannot be built here — portaudio.h is
#   absent, only the libportaudio2 runtime is installed. Installing it normally
#   fails with "fatal error: portaudio.h: No such file or directory".
#
#   pyaudio is imported in exactly ONE place in the whole package:
#   `Synth.start()`, which loads a soundfont and starts real-time playback
#   through it. Nothing else touches it. This file previously said the way
#   around pyaudio was "we render offline via generate_simple()", which is
#   half a route: generate_simple() itself is clean, but you only reach a
#   loaded soundfont by `start()` or `sfload()`, and `start()` is the one that
#   explodes. The way around it is `sfload()`.
#
#   The working sequence, verified against 0.3.7:
#       sfid = synth.sfload(path, gain=...)   # returns the id; no pyaudio
#       synth.program_select(channel, sfid, bank, preset)
#       synth.noteon(channel, midi_note, velocity)
#       buffer = synth.generate(samples)      # or generate_simple(samples)
#       synth.noteoff(channel, midi_note)
#
#   `generate*` returns a **memoryview of stereo float32** — four bytes per
#   sample per channel. Reading it as float16, or reshaping it without dividing
#   by the channel count, produces a buffer full of NaN and a peak above 1.0
#   that never happened. Cost us a confusing afternoon once; worth writing down.
#
#   Optional in practice: the numpy pluck synth needs nothing at all and takes over
#   when this is absent. (Named "pluck" and not Karplus-Strong: KS is a per-sample
#   recurrence, so rendering a five-minute chart with it in Python takes minutes.
#   A fallback slower than the thing it stands in for is not a fallback.) Locked in by tests/test_audio_deps.py, which
#   asserts pyaudio is absent and that tinysoundfont imports without it.

tinysoundfont==0.3.7
