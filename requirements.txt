# Guitaroids — runtime dependencies.
#
# Eight direct dependencies, curated by hand. Read this file before changing it:
# three of these packages cannot be installed by a plain
# `pip install -r requirements.txt`, for reasons that are not configuration
# mistakes and cannot be fixed by editing this file.
#
#   ==> Use `scripts/setup.sh`. It is the only supported install path.
#
#
# 1. OpenCV ordering
#    mediapipe hard-requires the *GUI* build of OpenCV (opencv-contrib-python),
#    whose bundled Qt plugins under cv2/qt/plugins hijack QT_PLUGIN_PATH and
#    break PySide6 with `Could not load the Qt platform plugin "xcb"`
#    (DESIGN.md §2.2). pip treats the two builds as unrelated distributions, so
#    listing the headless one here does not stop the GUI one being installed too.
#    Both write to the same cv2/ directory, so the GUI build must be REMOVED
#    BEFORE the headless one is installed. The reverse order deletes the headless
#    files while leaving its dist-info behind, and pip then reports "already
#    satisfied" and restores nothing — leaving `import cv2` broken. This happened;
#    it is now asserted by tests/test_m0_window.py.
#
# 2. tinysoundfont
#    Its declared dependency is pyaudio, which has NO Linux wheel in any release
#    and cannot be built here (portaudio.h is absent; only the libportaudio2
#    runtime is installed). Installing it normally therefore fails outright.
#    We never need pyaudio: it is imported in exactly one place in the package,
#    `Synth.start()`, which is a convenience loader we do not use. It lives in
#    requirements-optional.txt, which setup.sh installs with --no-deps.
#
# 3. Soundfont and model
#    Not Python packages. Fetched by scripts/fetch_model.sh and
#    scripts/fetch_soundfont.sh, and gitignored.
#
# The numpy Karplus-Strong synth is the fallback when tinysoundfont is absent, so
# the app still makes sound with only this file installed.
#
#
# WHY THIS FILE IS SHORTER THAN THE VENV
#
# Transitive dependencies live in requirements-lock.txt, which is `pip freeze` of
# one working environment. The venv has ~30 packages; this file has nine. A
# transitive may be pinned here only with a stated reason, and exactly one is
# (`attrs`, below). The notable transitive pulls that are deliberately absent are
# matplotlib, pillow, contourpy, cycler, fonttools, kiwisolver and pyparsing — all
# of them mediapipe's, and none of them imported by this project. Use the lock file
# to reproduce an environment; use this one to know what we actually depend on.
#
# WHY A PIN IS HERE
#
# "Imported today" means some module in guitaroids/ does `import <it>`. A pin
# marked for a milestone is deliberate and named: it is the dependency the next
# piece of work needs, pinned now so the version is decided before the code that
# relies on it exists. Both kinds belong here, and pretending otherwise is how
# requirements.txt becomes either a `pip freeze` in disguise or a wish list.
#
#   imported today      PySide6, shiboken6, numpy, opencv-contrib-python-headless,
#                       PyGuitarPro, attrs (a deliberate transitive pin)
#   audio milestone     sounddevice (§1.5, the master clock), soundfile (§3.1,
#                       decoding) — neither is imported yet; no audio has ever
#                       played
#   hand tracking       mediapipe (§15) — not imported yet, and it is the package
#                       that brings the OpenCV problem in point 1

PySide6==6.11.2
shiboken6==6.11.2
mediapipe==1.0.1
numpy==2.2.6
opencv-contrib-python-headless==5.0.0.93   # must match the version mediapipe pulls
soundfile==0.14.0
sounddevice==0.5.6
PyGuitarPro==0.11

# The one transitive we pin on purpose. It is a dependency of PyGuitarPro, which
# uses it for its frozen models, and pinning it means a future attrs release
# cannot change how tabs are read out from under a tested parser. Everything else
# transitive is in requirements-lock.txt.
attrs==26.1.0
